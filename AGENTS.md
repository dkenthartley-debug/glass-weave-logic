# Project architecture

- Keep owner-approved legacy photography and captions in a shared typed registry, with reusable photo sections on technology and market pages, so the same construction stays consistently identified wherever it appears.
- Use the shared Figure's contain option for documentary product photos, so complete mats, connectors and window edges remain visible rather than being cropped.
- Keep new gallery and inspection photographs in a shared typed registry backed by CDN pointers; redact sensitive identifiers in the uploaded pixels, never with browser overlays, so originals cannot be exposed by opening an image.
- Render vehicle application lists through the shared market-detail page keyed by market, so civilian and armoured-platform scope stays separate without duplicating page layouts.
- Keep S.02 shielding specification copy in a shared typed data module and expose a readable specification page, so SCIF scope is searchable and owners can review without opening a PDF.
